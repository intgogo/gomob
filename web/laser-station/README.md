# 3D 扫描工位管理台

这个目录是一个静态网页应用，用来管理激光 3D 扫描工位。

## 启动

```bash
cd server
export GOMOB_LASER_STATION_PASSWORD="$(openssl rand -base64 24)"
printf '%s\n' "$GOMOB_LASER_STATION_PASSWORD"
go run ./cmd/laserstationweb
```

浏览器打开：

```text
http://127.0.0.1:5177/
```

默认后端 Gateway 目标是 `http://127.0.0.1:18808`；浏览器侧默认通过本站 `/gateway` 反代访问。登录后，网页会自动从 `/station/session` 获取短期 access token 并填入连接面板，实时点云通过 `/v1/ws?token=...` 接收。

网页只接受 `GOMOB_LASER_STATION_PASSWORD` 指定的至少 16 字符高熵口令。登录成功后服务会签发 admin 网关 JWT；未配置或口令过弱时服务拒绝启动。登录态默认在当前浏览器保留 30 天。

可选环境变量：

- `GOMOB_LASER_STATION_ADDR`：监听地址，默认 `127.0.0.1:5177`。
- `GOMOB_LASER_STATION_GATEWAY`：覆盖 Gateway 地址。
- `GOMOB_LASER_STATION_PUBLIC_GATEWAY`：覆盖浏览器侧看到的 Gateway 地址；默认使用本站 `/gateway` 反代。
- `GOMOB_LASER_STATION_USER_ID`：自动签发 token 的用户 id，默认 `1`。
- `GOMOB_LASER_STATION_ROLE`：自动签发 token 的角色，默认 `admin`。
- `GOMOB_LASER_STATION_SESSION_DAYS`：登录态保留天数，默认 `30`，范围 `1-90`。
- `GOMOB_LASER_STATION_COOKIE_SECRET`：固定 cookie 签名密钥；不设置时从高熵管理口令派生，服务重启后已登录浏览器仍可继续使用。

## 功能

- 工位管理：新增、删除工位；浏览器保留界面草稿，正式 A/B 外参同步到服务端权威表。
- 相机管理：给每个工位维护多个激光相机，默认镜头 A 为 `192.168.9.101`，镜头 B 为 `192.168.9.102`。
- 扫描控制：起扫前回读服务端外参、区域、背景与 A/B READY 状态；普通扫描要求兼容背景，背景采集同样要求已保存并启用的区域；区域草稿未保存时一律阻塞起扫，可显式“放弃草稿”恢复服务端版本。
- 相机控制：刷新状态、守望、停止、回零、清错、软重启。
- 扫描配置：下发当前 App 中使用的扫描运动配置，支持“初始位置 + 扫描角度”。
- AB 标定：在“实时取景标定”里用 RGB 相机图完成。设备扫描参数读取完成后才开放运行，前后端共同拒绝空值、反向、过小或越界扫程；每次操作使用不可复用的 `session_key`。停止只有在服务端确认会话取消、外参未提交且 A/B 都回到 READY 后才解锁；若提交先发生，界面会回读服务端权威外参并明确提示。自动模式识别共享 ArUco/AprilTag 标记；手动模式在 A/B 两路 RGB 帧上标同名物理点，取景图支持缩放、旋转、平移后精确落点。点云点对只保留为诊断，不作为正式工位外参。

## 界面结构

- 顶部毛玻璃指挥条常驻展示当前工位、实时连接和真实就绪链；A/B、外参、区域、背景分别显示就绪、告警、阻塞或读取中，不再等起扫后才用 Toast 暴露缺项。
- 中央暗色点云工作面保留分镜、融合、视角、漫游、相机小窗和外廓测量；画布与标注层继续使用同一坐标系。
- 左侧维护轨只映射现有工位、扫描、设备、标定四个真实面板；顶栏只保留反馈与主操作“开始扫描”，工位维护和空场采集归入对应维护流程，避免重复入口。
- 右侧控制中心按日常工作流组织；Gateway、Token、手动点云调整和 RGB 点对收进高级诊断，避免开发参数占据日常操作面。
- 桌面、窄屏和手机宽度均保持点云工作面可用；手机支持单指拖动和双指缩放，不支持 `backdrop-filter` 的浏览器自动使用高不透明度降级材质。

## 标定建议

自动标定优先贴共享标记场，确保两路 RGB 图都能看到足够公共标记。手动点对也必须在 RGB 图里标同名物理点；单帧任意 2D 点对尺度欠约束，需已知尺度靶点 / 标记角点或多航向观测才能求解。计算结果会输出两份：

- `b_to_a_mm`：网页和端侧调试使用，平移单位是毫米。
- `b_to_a`：当前 native C-ABI 的 site 外参格式，平移单位是米。网页会把已翻转的显示坐标矩阵按 `F*T*F` 转回 native 原始坐标后再传给 worker。

正式外参通过 `GET/PUT /v1/scans/laser/site-calibration` 按 A/B IP 对持久化。Android 起扫不依赖浏览器状态，
worker 会从同一服务端配置解析；未配置时明确拒绝 `align=site`，不会静默退化为 raw。自动标定的 RMS 和公共
标记数会与矩阵一起保存；缺失指标保持“未知”，不得伪装成 0 误差。
