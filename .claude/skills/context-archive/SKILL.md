# 会话上下文归档

把本次会话产生的有历史价值的信息, 增量归档进 `docs/context/` 模块级历史上下文文档, 防止下次会话失忆重启。

## 步骤

1. **回顾本次会话**, 列出: (a) 新决策与理由 (b) 被证伪的假设 / 路线 (c) 里程碑进展与现状变化 (d) 新踩的坑 (e) 未竟事项变化。用户的拍板与纠偏原话价值最高, 优先保留。
2. 打开 `docs/context/INDEX.md`, 确定每条信息归属的模块文档 (可多篇); 全新领域 → 按现有文档的模板新建一篇并在 INDEX 加一行。
3. **增量写入**对应文档对应节: 决策按日期插入"决策时间线"; 证伪写进"禁区与已证伪路线"; "使命与当前状态"和"未竟事项"直接改写为最新。引用 finding 文件 / commit hash 而不复制全文; 与 `docs/agent-memory/` 重复的细节只留指针。
4. 刷新每篇被改文档头部的 `最后更新: <日期> | 截至 commit: <hash>` 戳 (hash 用 `git rev-parse --short HEAD`)。
5. 若某条信息是**点状可复用经验** (单一主题结论), 同时按 AGENTS.md「记忆写作硬规」落 `docs/agent-memory/` 新文件, 更新 `AGENTS_MEMORY.md` 索引并跑 `./scripts/check_doc_index.sh`。
6. `git commit` 归档改动 — 只 add `docs/context/` 与 `docs/agent-memory/` 相关文件, 不夹带工作区其他改动; 不 push。

## 硬规

- 增量更新, 不重写整篇; 不删已有禁区条目 (禁区是防重走弯路的护栏)。
- 无新决策 / 新证伪的纯执行会话 → 只更新现状与未竟事项, 甚至零改动, 不硬凑内容。
- 中文, 简洁, 无占位符; 订正既有结论时写"当时认知→证伪→新结论", 不悄悄改写历史。
