# 06 — 产品功能与信息架构

> 来源：`/root/WindowsR/berxel/snap/` 15 张早期设计稿。本文档是产品功能的**单一真理源**，
> 所有 feature 模块切分、UI 实现、服务端能力反推都以此文档为依据。

## 1. 业务本质

**用户场景**：机动车检测站查验员（员工号 `ZAA0120230001` 格式，归属某检测站，例：`杭州市西湖区车管所检测站`）
在工位现场对送检车辆做查验：

1. 拿出手机 + 外接 Berxel 深度相机
2. 拍/扫描车辆关键部位：**VIN 车架号、铭牌、外观、ODB 检测口**
3. 后端「智能预审」AI 检查 → 给出 `存在预警 / 暂无预警` 结论
4. 监管中心可远程视频通话实时监督
5. 后续抽查复核员对历史查验做抽样审核（结果正确 / 结果错误）

**角色**：
| 角色 | 职责 | 在 App 中 |
|------|------|----------|
| 查验员 | 在工位查验车辆 | 主要用户 |
| 监管员 | 视频通话远程督查 | 同样 App，但身份切换 |
| 复核员 | 抽查复核历史查验 | 同样 App，「协作 → 抽查复核」入口 |
| 管理员 | 用户审核 / 组织管理 | Web 后台（不在本仓） |

**注册必须后台审核**（截图明确："提交成功，请等待后台审核通过"）。

## 3. 各 tab 详细功能

### 3.1 首页 — 智能预审

**主屏（"智能预审"）**：
- 顶部 chip 分类：`所有车辆 / 已审通过 / 车型代码 / OBD检测异常 / 外观尺寸异常 / 待复核`（横向滑动）
- 数据卡（双卡，横向）：
  - 红色卡：`存在预警 183 (起止 2025/12/05 11:43)`
  - 绿色卡：`暂无预警 107 (起止 2025/12/05 09:12)`
- 「今日预审」5 联数字小卡：`56 28 20 22 44`（车型代码异常 / OBD 异常 / 外观异常 / 年份码异常 / 一切正常）
- 「最近预审」列表：每条 = 车辆缩略图 + VIN（`LSVHM133022221761`）+ 厂家代号（`大众系列, 小型汽车`）+ 备注（`OBD 检验, 外廓尺寸检测异常`）+ 时间
- 详情页：完整预审报告（车架号图、VIN 号、车型号、车架号、年份码、出厂日期、车辆品牌、车辆类型、车辆颜色、不予通过原因等）

### 3.2 消息

**消息列表**：
- 顶部「消息列表 / 在线求助」两个 chip
- 搜索框
- 列表项：头像 + 姓名 / 群名 + 最后一条消息预览 + 时间
- 特殊频道：`监管中心`（绿色喇叭头像）、`系统消息`（喇叭头像）

**单聊**：
- 标准聊天气泡
- 消息类型：文本、图片、`[视频通话 56:02]`、`[视频消息]`、`[图片]`
- 底部工具栏：图片 / 拍摄 / 视频通话

**视频通话进行中**：
- 全屏远端视频
- 角落自身预览
- 通话时长、挂断按钮

### 3.3 协作（多方协作）

**主屏（顶部 3 chip）**：
- `第一视角` — 实时第一视角直播 / 录像分享（其它查验员视角）
- `抽查复核` — **核心**复核流程
- `案例公开` — 公开案例库（培训用）

**抽查复核详情**：
- 数据卡 4 联：
  - `今日复核 26（环比 24.53%↑）`
  - `待复核 37（今日新增 8）`
  - `历史复核 1132（近 7 日新增 327）`
  - `历史过期 3（今日过期 0）`
- 主 CTA：`开始复核`
- 数据概况：复核趋势折线图（核对数据 vs 时间）
- 即时预警 计数 `127`（结果正确 + 结果错误堆叠 bar）

**单条复核**：
- 周 / 日 双层日历（23-33 周 / 01-37 日，红点=即时预警 / 绿点=无预警）
- 异常清单：`合规性异常 / 年份代码异常 — S/T  出厂日期 2021.07  车辆年份代码 F`
- 审核结果：`车架号年份代码验证异常，核验未通过`
- 图片：车架号图 / 辅助图（多张）
- 三按钮：`结果正确 / 结果错误 / 跳过`

### 3.4 3D（原"装备" → 改名）

> **本 tab 是当前 gomob 工程的硬件核心** — Berxel iHawk 深度相机与手机主摄像头深度绑定的入口。
> 之前临时 feature 模块 `:feature:calibration` + `:feature:scan` + `:feature:gallery` 全部合并到 `:feature:scan3d`。

**主屏**（两入口卡片，并列）：
- **标定**（图标：调节旋钮）— 进入双摄外参标定向导
- **扫描**（图标：AR 立方体）— 进入扫描主流程

**主屏附加**：
- 设备状态卡：`Berxel iHawk-072 已连接 / 未连接 (USB-C OTG)`
- 当前标定状态：`已标定 / 未标定 / 上次标定时间`
- 「最近 3D 资产」缩略列表

**扫描页**（沿用 29313af5 设计）：
- 全屏 RGB 预览（半透明叠加点云覆盖层）
- 顶部蓝色进度卡：`今日已扫描 N 辆 / 当日预警 N`
- 底部 CTA：`下载查验单 PDF`
- 拍摄按钮 + 切换主/深度预览

**标定页**：
- 引导拍 N 帧 Charuco 标定板（界面提示"将标定板对齐方框"）
- 实时显示已采集帧数 / 重投影误差
- 求解后写入 Room

### 3.5 我的（"更多"）

- 卡片：头像 + 姓名 + 工号 + 检测站
- 列表入口：
  - 个人信息（登录用户名 / 真实姓名 / 工号 / 所属组织）
  - 账号与安全（修改密码）
  - 通用（清除缓存）
  - 网络设置（**网关 IP** `112.145.10.91` + **端口号** `8808`）
  - 通知设置（通知开关 + APP 内通知 + 系统通知栏 三 toggle）
  - 关于
- 底部双按钮：切换账号 / 退出登录（红色）

### 3.6 登录 / 注册

**登录**：账号 / 密码 / 图片验证码（4位） / 记住账号 / 登录 / 没账号？去注册

**注册**：
- 真实姓名
- 查验员工号
- 说明信息（说明隶属检测站名称）
- 登录用户名
- 设置登录密码 / 再次确认密码
- 提交注册 → toast 「提交成功，请等待后台审核通过」

## 4. 反推的服务端能力清单（→ 第 14 / 15 任务的依据）

| 能力域 | 关键 API / 功能 | 实现方式 |
|--------|----------------|----------|
| **认证 / 身份** | 登录、注册（含审核流）、改密码、刷新 token | HTTP + JWT |
| **组织 / 角色** | 检测站组织树、查验员/监管员/复核员/管理员角色 | RBAC |
| **车辆 / 查验** | 车辆档案、查验记录 CRUD、智能预审结果落库、状态机 | HTTP（CRUD） |
| **资产** | 图片 / 3D 扫描数据 / PDF 报告 上传/下载 / 缩略图 | 对象存储（MinIO/OSS）+ 内容寻址 |
| **消息** | 消息列表、单聊、群、系统消息推送 | WebSocket（在线）+ HTTP（离线拉取） |
| **视频通话信令** | WebRTC offer/answer/ICE candidate 转发 | WebSocket signaling |
| **协作 / 抽查复核** | 第一视角直播、复核任务分发、复核结果回写、统计 | HTTP + 长连接 + 流媒体 |
| **预审 AI** | 接收扫描数据 → OBD/外观/合规校验 → 出预警 | 独立 worker，gRPC 给 API 服务 |
| **网关** | App 只配单一 IP:Port，反向代理到内部各服务 | 网关层 |
| **推送** | APP 内推 + 系统通知栏 | WebSocket + FCM/小米/华为推送通道（待选） |

## 5. 与当前 gomob 工程的差异（迁移路线）

当前已建：`feature:home / scan / gallery / calibration / settings`
目标：`feature:auth / home / message / collaboration / scan3d / profile`

**迁移**：
- `feature:home` → 重写内容（5 tab 主页 + 智能预审）
- `feature:scan` + `feature:calibration` + `feature:gallery` → **合并到** `feature:scan3d`
- `feature:settings` → **改名 + 扩展** `feature:profile`
- **新增** `feature:auth` / `feature:message` / `feature:collaboration`

**Navigation 重组**：
- 顶层走 `Scaffold` + `NavigationBar`（5 tab）
- 鉴权未通过 → 走 `feature:auth` 单独栈
