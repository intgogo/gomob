# VIN 去阴影二值化「质量闸」删除：无有效信号的调参式兜底（2026-06-21 立，2026-06-24 订正）

## What（2026-06-24 订正：质量闸已删除）

`signatureBinarize` 的**墨水占比质量闸**（`ink > SigInkMax(0.25)` → `ErrLowQuality` → 端侧"判废重拍"）已从服务端
`server/internal/cvengine/restore/`（删 `signature.go` + 闸逻辑 + `InkRatio` 字段）和 harness `ortho_metric.py` 删除。
真机 21 组复测证它**误判废 43%（9/21）的真实好采集**：被判废的 cap_007-015 实测**锐度 Laplacian 347-886（不糊，
甚至比通过组更锐）、高光饱和 ~0%、对比 std 27-42（良好）** —— 客观是好采集，只是板面有真实污渍/阴影、或度量
网格越过板缘采到暗带，被去阴影二值化当成「墨水」灌成 40-48%。鋭度/饱和/对比**都不能判别坏采集** → 这个闸
**没有有效信号**，是 `if ink>0.25` 的拍脑袋调参式兜底。

## Why（订正）

- 旧结论"7 组坏采集正确判废"是**错的**：那不是坏采集，是好采集被脆弱二值化误伤。离线只有少量同条件数据时
  又一次假阳性（同[[finding_vin_signature_binarize_realdevice_2026-06-21]]早先的极性假阳性同一类病）。
- 用后处理观感/二值占比去**反推采集好坏**本身方向错：墨水占比衡量的是「二值化把多少像素判成前景」，它把刻字、
  污渍、阴影、越界暗带全混在一起，与「这张能不能用」无因果关系。
- 违背[项目魂：扫描真实化](principle_first_principles_no_compromise.md) 与[整体视角不打补丁](feedback_holistic_not_patching.md)：
  用一个无验证的阈值兜表象，把真实好采集挡在门外，又不解决真实噪声（板脏/光不匀）。

## How to apply

1. **坏采集判别靠真实链路信号**，不靠后处理二值占比：OBB 检测失败（无承印面）、tilt 门（承印面过斜）已兜住
   主要坏例；要更强的质量闸，**先用 harness 标注好/坏样本**，验证某指标（聚焦方差/越界占比/平面 RMS/检测分）
   真能分离，再设阈 —— 不再拍脑袋。
2. **噪声是真实板面状态（污渍/阴影/镜面）+ 网格越界暗带**，治在**采集端（补光角度/曝光/避镜面反射）**或
   几何端（网格裁到有效板面），**不用去阴影滤镜伪装干净**（cap_003 干净采集本身就干净 → 路径是好采集而非滤镜）。
3. **不向用户出「补丁口味」选择题**（去阴影/raw/黑白 三选一就是反例，违背[第一性最优 §#6](principle_first_principles_no_compromise.md)）：
   先实测根因，再给唯一正确解。
4. `signature_binarize` 仅保留在 harness 供 `_sig` 重合分析/未来 OCR，**不再据此判废**。

**通用教训**：① 用「输出后处理的统计量」反推「输入采集质量」是因果倒置，几乎必假阳性；② 任何 `if metric>阈值`
的废弃门，上线前必须有 harness 证明该 metric 在好/坏样本上真能分离，否则就是调参式兜底；③ 见噪声先回采集/几何
链路找真因，不在末端加滤镜糊弄。详见 [[finding_vin_rectify_serverside_calib_2026-06-18]]。
