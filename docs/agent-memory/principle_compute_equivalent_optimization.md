# 省算力的优化必须结果等价

## 规则 / Why

为省算力、省带宽、省电做的优化，**只允许"结果等价 (result-preserving)"的变换**，不许"明智地牺牲一点保真"。这不是取舍题——它把"为了跑得快要不要降低扫描/重建质量"这类取舍**直接取消**。

这是项目魂（扫描真实化）落到工程层的硬约束：真实=扫描结果经得起近距离量测和反复复现。一个偷偷降了保真度的"优化"，等于用更便宜的方式伪装真实 RGBD 链路，本质和漂亮预览、硬编码姿态、单帧 demo 同罪。

把扫描链路一刀切成两层，每层答案被这条约束唯一逼定：

| 层 | 是什么 | 唯一答案 |
|---|---|---|
| **保真因果层** | 深度反投影、外参变换、多视角配准残差、TSDF 融合权重、误差阈值 —— 决定最终几何/纹理的本体 | **不许任何改结果的"省"。** 精度阈值、有效距离裁剪必须能追溯到 [P100R3 规格](reference_iHawkP100R3_spec.md)。 |
| **派生投影层** | 实时预览点云、HUD 缩略图、回看视角下采样 —— 权威重建结果的**纯函数** | **可惰性精确**：预览随便降采样/跳帧，因为它不回流喂配准与融合；离屏的视角不渲染。 |

派生层能省得完全等价的根因：它是权威结果的纯函数，怎么显示都不改变落盘的点云/网格。降预览分辨率不是降保真，因为量测和复现读的是权威层，不是预览层。

## How to apply

- **任何"省"先过这把尺子**：它改不改最终落盘的几何/纹理/位姿？改 → 禁，无论目标多"省电""省流量"。
- **常见伪装次优（默认禁，除非 harness 证等价）**：
  - 深度降采样 / 跳帧后直接喂配准与融合——少的点和帧改了 ICP 残差和补洞结果。
  - 缓存复用上一帧位姿当本帧外参——漂移被掩盖，复现性破坏。
  - 端云裁剪点云：端上裁掉"看着没用"的点再上传——云端 Open3D multiway_registration / PGO 看到的是不同输入，结果不可复现。
  - 降分辨率重建当默认档——TSDF voxel 变粗，量测误差超阈还自称"优化"。
- **合法手段（可证等价，优先用）**：去重/合并重复帧、空间索引把 O(N²) 邻域查询降到近 O(1)、惰性物化预览、对纯派生计算做 memoization、零拷贝传大数据（[DirectByteBuffer/native 指针](../architecture/03-jni-boundary.md)，传通道变了但字节不变）。
- **必须 harness 证等价，否则不许进主线**：在 `tests/harness/scan_quality/` 或 `cv_vin_pipeline/` 跑优化档 vs 全量档，`analyze.py` 给可判定结论——配准残差、网格 RMSE、有效深度占比、metric 尺度误差都在阈内才算等价；任一项掉出阈值，这个"优化"就是有损的，该砍不该藏在 flag 后面。
- **发现现存的"快速档/LOD"其实降了保真层** → 它是约束违背，该修该删，不是该保留统一的功能。
